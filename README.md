What I did in this project:

Cleaned and prepared the data by fixing missing values, checking for duplicate IDs, and joining the 75k appointment records with the 320 doctors dataset using a left join.

Calculated no-show rates properly by only looking at completed, no-show, and cancelled appointments (left out scheduled ones so the numbers stay accurate).

Filtered the dataset to completed visits only when looking at wait times, doctor utilization, patient satisfaction, and revenue calculations.

Summarized key trends around what causes missed appointments, how different booking channels perform, and which specialties generate the most revenue.
